# Touch stroke collector work in progress

This directory contains an unfinished browser recorder on a temporary collection branch. Its current IndexedDB storage and direct React flow predate the decision to use Lightmill. They are reference code, not a working collection tool. The collector and its dependencies stay off the main branch; the revision used for recording will be retained with an archival tag.

Finish [Separate the library and demo into workspaces](https://github.com/QuentinRoy/Marking-Menu/issues/530), then [Set up local Lightmill logging for the touch collector](https://github.com/QuentinRoy/Marking-Menu/issues/531), before completing [Build the stroke collection tool](https://github.com/QuentinRoy/Marking-Menu/issues/523). The last ticket must verify the complete tablet recording and export flow before any corpus is recorded.
