# Log touch strokes to a local Lightmill server

The touch stroke collector runs from a temporary branch in a tablet browser over local HTTP and uses Lightmill to write each completed trial to SQLite on the laptop. Browser storage alone can be evicted between recording days, and local HTTPS would require certificate or tunnel setup. Trials are logged without waiting for the server between strokes. A failed log stops the run, and it resumes after the last saved trial. The collector opens a host session so a run stays resumable after the server restarts, and it rebuilds the same timeline from the session number. The laptop database is backed up after each session, and a separate export produces the corpus files. The collector uses Lightmill's React experiment flow and never runs the marking menu recognizer.
